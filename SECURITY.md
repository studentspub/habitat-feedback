# Sicherheitslücken melden

Habitat Feedback wird privat und unkommerziell betrieben. Wenn du eine Sicherheitslücke findest (z. B. XSS,
Injection, Umgehung des Mehrfachbewertungs-Schutzes, Zugriff auf Daten anderer), melde sie bitte **nicht** als
öffentliches Issue, sondern vertraulich:

- über GitHub: Reiter **Security** dieses Repos → **Report a vulnerability** (private Meldung, nur der Betreiber
  sieht sie), oder
- falls das nicht geht: eine Direktnachricht an den Account `studentspub` auf GitHub.

Bitte beschreibe, wie sich das Problem nachstellen lässt. Eine Antwort gibt es in der Regel innerhalb einer
Woche; behobene Lücken werden im zugehörigen Commit genannt, ohne Details zum Melder, wenn das nicht gewünscht ist.

Nicht in den Rahmen fallen Meldungen zu Drittdiensten, die die Karte nur einbindet (OpenStreetMap-Kacheln,
WMS-Dienste von Behörden), sowie Funde, die ausschließlich Zugang zum Betreiber-Netz voraussetzen.
